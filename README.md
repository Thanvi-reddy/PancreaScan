## 📌 Overview

PancreaScan is an advanced AI-powered Android application developed for detecting pancreatic edema and pancreatitis from CT scans using Federated Learning principles.

Unlike traditional cloud-based AI systems, PancreaScan performs model training locally on-device and only shares encrypted model updates instead of raw patient images, ensuring strong medical data privacy and compliance.
